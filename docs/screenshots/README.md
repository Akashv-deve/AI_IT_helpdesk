# Screenshots

Drop your own captures here and they will appear in the main README.

Expected filenames:

| File | What to capture |
|---|---|
| `helpdesk.png` | The chat page after answering a Wi-Fi problem, with Agent details expanded |
| `escalation.png` | The escalation banner with a visible ticket ID |
| `tickets.png` | The Tickets page with at least one ticket and the status selector open |
| `dashboard.png` | The Dashboard with non-zero counters |
| `diagnostics.png` | The Diagnostics page after running the MCP handshake |

Use a 1440px-wide window and light mode for consistency.
